# Spa MC — Web

Reconstrucción de la web de Spa MC, salón de belleza en La Puebla de Cazalla (Sevilla).

🔗 **En vivo**: https://marutri.github.io/spa-mc-web/

## Estructura

- `docs/` — las 4 páginas del sitio (`index.html`, `servicios.html`, `nosotros.html`, `contacto.html`), SEO on-page (meta tags, JSON-LD, sitemap.xml, robots.txt), CSS/JS inline en cada página, y `docs/assets/` con el logo, el vídeo del hero y la galería de fotos reales del salón. Es la carpeta que publica GitHub Pages.

## Ver la web en local

Abre `docs/index.html` con Live Server (o cualquier servidor estático) — no funciona bien abriéndolo directamente por `file://` porque el vídeo y las rutas relativas lo necesitan.
