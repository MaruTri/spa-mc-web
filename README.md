# Spa MC — Web

Reconstrucción de la web de Spa MC, salón de belleza en La Puebla de Cazalla (Sevilla).

## Estructura

- `WEB SPA/` — las 4 páginas del sitio (`index.html`, `servicios.html`, `nosotros.html`, `contacto.html`), SEO on-page (meta tags, JSON-LD, sitemap.xml, robots.txt) y CSS/JS inline en cada página.
- `assets/` — logo, vídeo del hero y galería de fotos reales del salón.

## Ver la web en local

Abre `WEB SPA/index.html` con Live Server (o cualquier servidor estático) — no funciona bien abriéndolo directamente por `file://` porque el vídeo y las rutas relativas lo necesitan.
